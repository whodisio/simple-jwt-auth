# case=3 — a malformed token fails loud, same error class

cells: C3 · sharp · critipath; C22 · happy · alterpath (the `isJSONWebToken` steps)

## .narrative

whodis-react reads a cookie that a proxy mangled to `abc`. it calls `getUnauthedClaims` from the subpath. the call throws `SimpleJwtAuthError: token does not match shape of a JWT`. the app's catch block checks `error instanceof SimpleJwtAuthError`, with the class imported from either the root or the subpath. both checks hold: one module file, `dist/SimpleJwtAuthError.js`, backs both entries, so there is one class.

## .[tn] sketch

```
given('a string that is not a jwt')
  when('[t0] getUnauthedClaims from simple-jwt-auth/unauthed is called on it')
    then('it throws SimpleJwtAuthError')
    then('the error is instanceof the SimpleJwtAuthError from simple-jwt-auth/unauthed')
    then('the error is instanceof the SimpleJwtAuthError from simple-jwt-auth')
  when('[t1] isJSONWebToken from simple-jwt-auth/unauthed is called on it')
    then('it returns false; no throw')
given('an absent token: undefined or an empty string (no cookie)')
  when('[t0] getUnauthedClaims is called on it')
    then('it throws the same SimpleJwtAuthError, not a raw TypeError')
  when('[t1] isJSONWebToken is called on it')
    then('it returns false; no throw')
given('a redacted token')
  when('[t0] isJSONWebToken is called on it')
    then('it returns true: a redacted token still has the jwt shape')
```
