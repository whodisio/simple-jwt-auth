# case=6 — the published tarball holds the subpath

cell: C16 · sharp · critipath (low freq, high cost: a silent break for every legacy consumer, seen only after release)

## .narrative

a maintainer adds `unauthed/package.json` but forgets `/unauthed` in `package.json` `files`. the symlink-based contract test still passes: it links the whole git root, so it sees the stub. ci instead packs the package (`npm pack`), unpacks the tarball into a temp `node_modules`, and looks up `simple-jwt-auth/unauthed` from there. the stub is absent from the tarball, so the test fails before release:

```
✋ ConstraintError: published tarball lacks the unauthed subpath
   ├─ absent: unauthed/package.json
   └─ fix: add "/unauthed" to package.json files
```

## .[tn] sketch

```
given('the package as npm pack emits it')
  when('[t0] a consumer requires simple-jwt-auth/unauthed from the unpacked tarball')
    then('it lands on dist/unauthed.js')
    then('the tarball holds unauthed/package.json and dist/unauthed.d.ts')
  when('[t1] a consumer requires simple-jwt-auth from the unpacked tarball')
    then('it lands on dist/index.js, as before')
given('a files list that omits /unauthed')
  when('[t0] the tarball test runs')
    then('it fails, and names the absent path and the fix')
```
