# case=5 — a ts node10 consumer finds the subpath

cell: C7 · sharp · critipath — every target consumer walks it. whodis-client, whodis-react, and whodis-react-storage-browser each extend `@tsconfig/node-lts-strictest`, which sets `moduleResolution: "node"` (node10).

## .narrative

the whodis-client maintainer switches one import to `simple-jwt-auth/unauthed` and runs `tsc`. her ts looks up `simple-jwt-auth/unauthed` as a plain directory, finds `unauthed/package.json`, follows `types` to `../dist/unauthed.d.ts`, and compiles. the emitted `require('simple-jwt-auth/unauthed')` then meets two runtimes: her jest suite (node) and the app's bundler (webpack 5 in app-storefronts-web). each reads the same stub's `main` and lands on `dist/unauthed.js`.

without the stub, her compile fails with `Cannot find module 'simple-jwt-auth/unauthed'`, and the wish fails for every consumer it names.

## .the trap for its proof

this repo's own `tsconfig.json` sets `moduleResolution: node16`. a ts test here type-checks under node16, not under the consumers' node10. the proof must compile a consumer fixture under `moduleResolution: node10` explicitly, or it proves the wrong mode.

## .[tn] sketch

```
given('a ts consumer on moduleResolution node10 (the whodis browser libs)')
  when('[t0] it compiles `import { getUnauthedClaims } from "simple-jwt-auth/unauthed"`')
    then('ts finds dist/unauthed.d.ts via unauthed/package.json types')
    then('the import carries full types: a wrong use fails the compile')
given('a package whose tarball lacks unauthed/package.json')
  when('[t0] the node10 consumer fixture compiles the same import')
    then('tsc fails loud: Cannot find module "simple-jwt-auth/unauthed"')
    then('the tarball test (case=6) fails first, in this repo, and names the fix: add "/unauthed" to files')
given('the same fixture compiled under node16 instead')
  when('[t0] it compiles')
    then('it may pass where node10 fails, so it never stands as the proof: the node10 run does')
given('a cjs runtime (node require, jest, webpack)')
  when('[t0] it requires simple-jwt-auth/unauthed')
    then('it lands on dist/unauthed.js via unauthed/package.json main')
```
