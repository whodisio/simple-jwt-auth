# case=2 — a server keeps its root import

cell: C4 · happy · critipath

## .narrative

the maintainer of an api service sees a minor bump of simple-jwt-auth in her dependency bot's pr. she reads the changelog: a new browser subpath. she merges the bump without a code change. her test suite runs: `getTokenFromHeaders` still pulls the cookie, `getAuthedClaims` still verifies the signature against the jwks, and a forged token still fails. she deploys, and her auth graphs look the same as last week. she never imports the subpath, and has no reason to.

the proof behind her calm: every name she uses still exports from the root, and `require('simple-jwt-auth')` still lands on `dist/index.js`.

## .[tn] sketch

```
given('a node service on the prior release, with an auth test suite')
  when('[t0] it bumps to the release with the subpath and changes no line')
    then('its suite passes as before: getTokenFromHeaders, getAuthedClaims, getSignedClaims behave the same')
    then('a forged token still fails verification')
    then('every prior root export still loads, with the same shape')
    then('require("simple-jwt-auth") lands on dist/index.js')
```
