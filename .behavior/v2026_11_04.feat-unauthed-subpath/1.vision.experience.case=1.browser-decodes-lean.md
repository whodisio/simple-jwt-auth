# case=1 — a browser decodes a jwt, lean

cells: C1, C2 · happy · critipath

## .narrative

the whodis-client maintainer opens `getAuthClaims.ts`. one line changes:

```ts
// before
import { getUnauthedClaims } from 'simple-jwt-auth';
// after
import { getUnauthedClaims } from 'simple-jwt-auth/unauthed';
```

ts autocompletes the subpath and its five names. she ships a patch. app-storefronts-web bumps it. the next lighthouse run shows the main chunk ~600kb lighter; total-blocked-time drops ~900ms. jwk-to-pem, elliptic, asn1.js, axios, parse-domain, and crypto-browserify no longer appear in the bundle analyzer. claims from a redacted cookie token decode exactly as before.

## .[tn] sketch

```
given('a browser app that decodes jwts from its auth cookie')
  when('[t0] it imports getUnauthedClaims from simple-jwt-auth/unauthed')
    then('ts resolves the import with full types')
    then('the bundle graph holds none of jwk-to-pem, elliptic, asn1.js, axios, parse-domain, crypto')
  when('[t1] it decodes a wellformed token')
    then('it returns the body claims')
  when('[t2] it decodes a redacted token')
    then('it returns the same body claims; the signature segment is ignored')
```
