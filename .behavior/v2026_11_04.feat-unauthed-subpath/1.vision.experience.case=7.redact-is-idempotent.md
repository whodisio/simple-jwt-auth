# case=7 — redactSignature is idempotent, and fails loud on junk

cells: C17 (happy), C18 (sharp), C19 (sharp) · critipath — whodis-react-storage-browser calls `redactSignature` in `src/logic/storage/setTokenToStorage.ts` on every store

## .narrative

the storage lib receives a fresh token from login and stores it redacted: `redactSignature` returns `header.payload.__REDACTED__`. a tab later syncs, reads the stored token back, and passes it through `setTokenToStorage` again. the token is already redacted. `redactSignature` returns the identical string: the `__REDACTED__` segment still fits the jwt shape, so the op swaps it for itself. no double mark, no throw, no churn in storage. `getUnauthedClaims` on either form returns the same claims.

a proxy mangles the cookie to `abc`, or the cookie is gone. `redactSignature` throws `SimpleJwtAuthError: token does not match shape of a JWT` at once, so the lib never stores junk as if it were a token.

## .[tn] sketch

```
given('a wellformed jwt')
  when('[t0] redactSignature from simple-jwt-auth/unauthed is called on it')
    then('it returns header.payload.__REDACTED__')
  when('[t1] redactSignature is called on that output again')
    then('it returns the identical string')
    then('isRedactedSignatureToken holds for it')
    then('getUnauthedClaims returns the same claims for both forms')
given('a malformed or absent token')
  when('[t0] redactSignature is called on it')
    then('it throws SimpleJwtAuthError')
    then('the error is instanceof the SimpleJwtAuthError from simple-jwt-auth')
```

## .grounds

`src/redactSignature.ts` guards with `isJSONWebToken`, then joins the first two segments with `__REDACTED__`. `JWT_REGEXP` (`src/isJSONWebToken.ts`) allows `[a-zA-Z0-9\-_]+` in the third segment, which `__REDACTED__` fits. `src/isRedactedSignatureToken.ts` defines "redacted" as `redactSignature({ token }) === token`, so the root already depends on this idempotency.
