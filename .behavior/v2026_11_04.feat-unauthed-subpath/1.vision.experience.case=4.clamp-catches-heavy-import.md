# case=4 — the clamp catches a heavy import

cell: C9 · sharp · critipath

## .narrative

six months on, a maintainer adds `isSameSite` to `getUnauthedClaims` to warn on cross-site issuers. the import pulls parse-domain into the decode graph. ci goes red before review:

```
✋ ConstraintError: simple-jwt-auth/unauthed reaches a forbidden dep
   ├─ dep: parse-domain
   └─ via
      ├─ dist/unauthed.js
      ├─ dist/getUnauthedClaims.js
      ├─ dist/domains/isSameSite.js
      └─ parse-domain
```

the chain names the file to fix. the maintainer moves the warn to the auth side; ci goes green. no browser ever ships the regression.

## .[tn] sketch

```
given('the built dist/unauthed.js')
  when('[t0] the clamp walks its static require graph')
    then('no node in the graph is jwk-to-pem, elliptic, asn1.js, axios, parse-domain, or crypto')
    then('every external dep in the graph is in the allowlist { buffer }')
given('a decode-side file that requires a forbidden dep at the top of the file')
  when('[t0] the clamp walks the graph')
    then('it fails, and names the dep and the require chain that reached it')
given('a decode-side file with a lazy require("crypto") inside a function body, as importCrypto.ts holds')
  when('[t0] the clamp walks the graph')
    then('it fails on crypto too, though no top-level line names it')
    then('a walker that misses this case is the wrong walker (Q7b): swap it, do not loosen the clamp')
```

## .why a static walk

bundlers walk the static graph, so the clamp walks the static graph too. a runtime `require.cache` read would miss a lazy `require('crypto')` inside a function body, as `importCrypto` holds today; a bundler would still pull the crypto polyfill in.
