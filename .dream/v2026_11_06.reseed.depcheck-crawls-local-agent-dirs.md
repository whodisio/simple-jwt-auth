# 🌙 dream: depcheck skips the local agent dirs

kind: reseed · owner: ehmpathy/declapract-typescript-ehmpathy (`.depcheckrc.yml` practice) · caught 2026-11-06

## .the cue that fired

`npm run test:lint` ran 809s locally (18s in ci) and failed on `* claude-code: ./.claude/plugins/marketplaces/.../tests/hostile.test.ts`.

## .the gap, precisely

the practice's `.depcheckrc.yml` sets `ignores` (package names) but no `ignore-patterns` (paths). in a rhachet-enrolled worktree, depcheck crawls the untracked `.claude/` (plugin marketplaces with their own tests) and `.agent/.actors/` trees. the crawl is slow, and a plugin's import reads as an undeclared dep. ci never holds these dirs, so ci stays green while every local lint fails.

## .the shape of the fix

in the practice template, add:

```yaml
ignore-patterns:
  - .claude
  - .agent
  - .temp
```

then a declapract upgrade carries it to every repo.

## .why it is not done in this round

this repo carries the local half (`ignore-patterns: [.agent, .claude]` in `.depcheckrc.yml`), so its own lint is green on an actor machine. the file is declapract-managed, so the next upgrade may revert it, and every other repo still crawls. the fix belongs upstream.
